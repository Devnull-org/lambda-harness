Project memory

Keep architecture, invariants, and decisions close to every conversation. New tasks use the current version. Existing tasks keep their own version until you change it.

You can also say “Save this to project memory” in General chat. The agent adds a note and shows the exact saved text in your conversation.

Plain text or Markdown. Up to 32,000 UTF-8 bytes; notes are included in full.

Adding a file reads all listed sources from the project's current committed HEAD. Editing notes or removing a file keeps the saved source contents. Use “Refresh sources & save” to read them again. Uncommitted changes are never imported.
